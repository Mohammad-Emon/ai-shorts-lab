## 🚀 How to Use

### Quick Setup & Launch
```bash
# Complete setup (installs everything)
python silas-chat-ui/setup_did_style.py

# Launch D-ID style system
python silas-chat-ui/launch_did_style.py
```

### What Happens
1. **Setup**: Installs SadTalker, downloads models, configures system
2. **Launch**: Starts backend server and opens D-ID interface
3. **Chat**: Type or speak messages
4. **Video**: Watch realistic lip-synced responses
5. **Controls**: Pause, stop, replay videos

### Features Available
- 🎤 **Voice Input**: Click mic or press SPACE
- 🔊 **Voice Output**: Natural TTS with video
- 📹 **Realistic Video**: SadTalker lip-sync generation
- 💬 **D-ID Interface**: Professional glassmorphism UI
- ⌨️ **Shortcuts**: P=Pause, S=Stop, R=Replay
- 🤖 **AI Chat**: Free OpenRouter LLMs
