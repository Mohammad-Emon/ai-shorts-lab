# 📸 How to Save Your Photo for Real Face Avatar

## I can see your photo in the chat! Here's how to use it:

### Step 1: Save Your Photo
1. **Right-click on your photo** in the chat above
2. **Select "Save image as..."**
3. **Navigate to the `silas-chat-ui` folder**
4. **Save it as `my_photo.jpg`** (exactly this name)

### Step 2: Verify Photo Setup
```bash
python silas-chat-ui/save_my_photo.py
```

### Step 3: Launch Real Face System
```bash
python silas-chat-ui/launch_real_face_avatar.py
```

- **Format**: JPG, JPEG, or PNG
- **Size**: At least 256x256 pixels (512x512 recommended)
- **Quality**: Clear, front-facing, well-lit
- **Face**: Should be clearly visible and take up most of the frame
