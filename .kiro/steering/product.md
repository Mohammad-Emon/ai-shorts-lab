# Product Overview

## AI Shorts Lab

This repository contains multiple AI-powered projects showcased in YouTube shorts and tutorials. The main focus is on rapid prototyping and deployment of AI applications.

### Core Projects

**Silas Chat UI** - The primary project featuring:
- Multi-agent AI chat system with specialized agents (Coordinator, Researcher, Creative, Technical, Analyst, Summarizer)
- Avatar video generation using SadTalker integration
- Voice synthesis capabilities
- Free LLM integration via OpenRouter
- Real-time chat interface with WebSocket support

**Supporting Projects:**
- **60s SaaS Pipeline** - FastAPI + Docker rapid deployment template
- **SadTalker** - AI-powered talking head video generation
- **Wav2Lip** - Lip-sync video generation
- **Slack Support Bot** - AI customer support automation
- **Prompt Chains** - Advanced prompt engineering templates

### Target Audience
- AI developers and enthusiasts
- Content creators building AI applications
- Developers learning rapid prototyping techniques
- YouTube viewers following along with tutorials

### Key Value Propositions
- Complete working examples with minimal setup
- Free/open-source alternatives to expensive AI services
- Educational content with step-by-step tutorials
- Production-ready code that can be deployed immediately
